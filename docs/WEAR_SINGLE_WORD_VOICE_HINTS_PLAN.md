# План однословных голосовых подсказок Wear

## Цель

Сделать голосовые подсказки в динамических списках на очках короткими и
визуально предсказуемыми: подчёркивать не более одного подходящего русского
слова в каждой строке.

Если одно слово соответствует нескольким элементам, приложение не должно
выбирать первый элемент автоматически. Оно должно открыть существующий экран
`Уточните фразу` и позволить пользователю назвать следующее различающее слово
либо выбрать элемент командами навигации.

## Область применения

Единое правило применяется ко всем текущим динамическим спискам на очках:

- выбор принтера;
- выбор товара при дубле штрихкода;
- выбор товарной группы;
- выбор товарной позиции;
- выбор дубля товара при прямом сканировании;
- экран уточнения голосовой фразы.

Статические голосовые команды, обычный текст интерфейса и списки на экране
телефона не изменяются.

## Правило выбора слова

Генератор просматривает слова названия слева направо и выбирает первое слово,
которое соответствует всем условиям:

1. Слово содержит только кириллические буквы.
2. Слово содержит больше одного символа.
3. Слово не содержит цифр.
4. Слово не является служебным: `в`, `во`, `на`, `для`, `из`, `с`, `со`, `к`,
   `ко`, `у`, `о`, `об`, `от`, `до`, `по`, `и`, `а`, `но`.
5. Слово не совпадает с зарезервированной голосовой командой текущего экрана.
6. Слово не было произнесено на предыдущем шаге уточнения.
7. Слово не исключено правилами текущего контекста уточнения.

Латинские и смешанные кириллическо-латинские слова пропускаются полностью,
поскольку текущая модель распознавания их не поддерживает. Слова, содержащие
цифры, также пропускаются полностью.

Генератор не составляет подсказки из двух или более слов и не ищет более
короткое уникальное слово в середине названия. Если подходящего русского слова
нет, строка остаётся без подчёркивания и доступна через фокус и команды
`вверх`, `вниз`, `выбрать`.

Примеры:

| Название | Подчёркнутое слово |
|---|---|
| `Молоко Простоквашино 2,5%` | `Молоко` |
| `Кефир Домик в деревне` | `Кефир` |
| `Coca Cola` | нет подсказки |
| `Coca Cola напиток` | `напиток` |
| `Adidas кроссовки мужские` | `кроссовки` |
| `A12 Молоко` | `Молоко` |
| `Товар12 Молоко` | `Молоко` |
| `123 456` | нет подсказки |

## Неоднозначные подсказки

Одинаковое слово разрешено подчёркивать у нескольких элементов.

Пример исходного списка:

```text
Молоко Простоквашино 2,5%
Молоко Домик 3,2%
Кефир Кубанский
```

В первых двух строках подчёркивается `Молоко`. После произнесения слова
`молоко` приложение должно:

1. Определить все совпавшие элементы по полному актуальному списку, включая
   элементы на других страницах.
2. Не выполнять прямой выбор элемента.
3. Открыть существующий экран `Уточните фразу` только с совпавшими элементами.
4. Исключить уже произнесённое слово `молоко` из следующих подсказок.
5. Подчеркнуть первое следующее подходящее русское слово: `Простоквашино` и
   `Домик`.
6. Разрешить выбор уточняющей фразой или командами `вверх`, `вниз`, `выбрать`.
7. Вернуть выбранный ID исходному экрану через существующий `onDynamicItem`.

Если после уточнения новое слово всё ещё соответствует нескольким элементам,
существующий экран уточнения должен сузить список повторно. Если элементы
невозможно различить допустимыми словами, остаётся выбор через фокус и команду
`выбрать`.

## Архитектурные изменения

### 1. Генератор подсказок

Изменить
`lib/modules/wear/domain/service/voice_command/voice_hint_generator.dart`:

- заменить поиск кратчайшей уникальной фразы на последовательный поиск одного
  подходящего русского слова слева направо;
- сохранить исходные позиции слова для корректного диапазона подчёркивания;
- разрешить одинаковую отображаемую фразу у нескольких элементов;
- формировать `itemIdByPhrase` только для фраз, которые
  `VoiceListMatcher` однозначно сопоставляет тому же элементу;
- не добавлять неоднозначную фразу в `itemIdByPhrase`;
- сохранять диагностическую проблему для элементов без допустимой подсказки.

Разделение обязательно: `hintsByItemId` может содержать одинаковые фразы для
отрисовки, а `itemIdByPhrase` не должен превращать общую фразу в ошибочный
прямой выбор последнего элемента.

### 2. Контекст уточнения

Синхронизировать исключённые слова между отображением и распознаванием:

- добавить контекст исключённых слов в `VoiceDynamicItemsSnapshot` либо
  передавать его единым способом во все точки построения индекса;
- использовать одинаковый набор исключений в `WearGlassesVoiceHints` и
  `SpeechRecognitionService`;
- на экране уточнения исключать все ранее произнесённые и общие слова.

Затрагиваемые файлы:

- `lib/modules/wear/domain/service/voice_command/voice_utterance_coordinator.dart`;
- `lib/modules/wear/domain/service/voice_typing/speech_recognition_service.dart`;
- `lib/modules/wear/presentation/screens/voice/wear_voice_clarification_screen.dart`;
- `lib/modules/wear/application/wear_flow_controller.dart`;
- `lib/modules/wear/presentation/glasses/wear_glasses_voice_hints.dart`.

### 3. Кэш подсказок

Изменить
`lib/modules/wear/domain/service/voice_command/voice_hint_index_cache.dart`:

- включить нормализованные исключённые слова в ключ кэша;
- гарантировать подготовку отсутствующего индекса, в том числе для списков
  больше синхронного лимита;
- не создавать параллельные индексы для одинакового контекста;
- использовать один результат для отображения и распознавания.

### 4. Существующий маршрут уточнения

Переиспользовать без нового экрана:

- `VoiceClarificationArgs`;
- `WearFlowController.handleVoicePhrase()`;
- `WearVoiceClarificationScreen`;
- `WearFlowController.selectVoiceClarificationItem()`;
- зарегистрированные `onDynamicItem` исходных экранов.

Не создавать новый распознаватель, аудиопоток, маршрут навигации или
MethodChannel-метод.

### 5. Отображение на очках

`WearVoiceHintText` продолжает подчёркивать переданный диапазон. Выбор слова не
переносится в UI. Схема `WearGlassesPayload` и Android bridge не изменяются.

## Критерии готовности

- В каждой динамической строке подчёркнуто не более одного слова.
- Подчёркнуто первое допустимое русское слово слева направо.
- Латинские, смешанные и содержащие цифры слова не подчёркиваются.
- Полностью неподходящее название остаётся без подсказки.
- Одинаковая подсказка может отображаться у нескольких элементов.
- Неоднозначная подсказка всегда открывает уточнение и никогда не выбирает
  произвольный элемент.
- После уточнения выбранный ID корректно возвращается исходному сценарию.
- Все динамические списки используют единое правило.
- Производительность больших списков не ухудшается из-за повторного построения
  одинаковых индексов.
